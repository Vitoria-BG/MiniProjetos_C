# Coleção de MiniProjetos em C

## Sobre
Este repositório contém pequenos projetos em C para praticar conceitos essenciais da linguagem, como **loops**, **funções**, **arrays** e **ponteiros**.

## Projetos
- Cadastro de pessoas
- Calculadora simples
- Jogo da forca
- Jogo da velha
- Mensagem personalizada com um coração
